# About me

I studied medicine (MD) at Shahid Beheshti University of Medical Sciences, but became deeply interested in evolutionary systems and computation.

I started programming with Pascal and eventually moved into x86_64 assembly, where I experimented with self-mutating software that evaluated and eliminated maladaptive offspring — a literal implementation of evolutionary selection in code.

Today I work primarily in Go, building systems at the intersection of:

* evolutionary computation
* machine learning
* deterministic simulation
* runtime engineering
* high-performance execution systems

My open-source projects are infrastructure extracted from a larger experimental genetic programming ecosystem.

# Ecosystem Projects

### gomnasium

Pure-Go Gymnasium-style RL environments with automated compliance validation against the reference Python implementation.

### box2go

Go wrapper for Box2D v2.3.0 via SWIG/CGo. Physics backend powering gomnasium environments.

### rawexec

Execute raw x86-64/386 machine code in Go with zero allocations and extremely low overhead.
