## About me

I studied medicine (MD) at Shahid Beheshti University of Medical Sciences,
but my path took an unusual turn. Fascinated by viral evolution and mutation,
I taught myself programming, starting with Pascal and eventually x86_64 assembly,
where I built self-mutating software that observed its own offspring and eliminated
the maladaptive — a literal implementation of evolutionary selection in code.

That obsession with evolution never left. Today I work primarily in Go, building
systems at the intersection of machine learning, evolutionary algorithms, and
performance engineering. My main project is a personal AI/ML research pursuit,
and everything else I build serves or supports that long-term goal.

I also:
- Developed and operated my own game for 8 years
- Worked on networking for MMO games
- Built web applications for companies and teams
- Invented and registered a bioreactor for cultivating Chlorella Vulgaris
- Teach programming privately across languages and frameworks
